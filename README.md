# 🔮 AI 사주 풀이

사주팔자를 계산하고, Gemini가 재물·연애·사업·건강운 등을 풀이해 주는 웹 앱입니다. DB·로그인이 없고, 풀이 방식은 두 가지입니다.

- **서버 공용 키 (기본):** 방문자는 키 없이 사용. Netlify Edge Function(`netlify/edge-functions/reading.ts`)이 환경변수 `GEMINI_API_KEY`로 Gemini를 호출하고 스트림을 중계합니다.
- **본인 키:** 설정에서 본인의 Gemini API 키를 입력하면 브라우저가 Google로 직접 호출합니다. (서버를 거치지 않음)

## Netlify 배포와 서버 키 설정

1. Netlify 사이트 → **Site configuration → Environment variables**에서 `GEMINI_API_KEY`를 추가합니다. (값은 Secret으로, 스코프에 Functions/Runtime 포함)
2. 환경변수를 추가한 뒤 **재배포**해야 적용됩니다.
3. 서버 키 모드는 **사용량 제한이 없습니다.** 방문자가 쓰는 만큼 내 키의 한도·요금이 소모되므로 Google AI Studio에서 사용량 알림/한도를 설정하세요. 서버는 모델 허용 목록, 프롬프트 길이(20,000자) 제한, 같은 사이트 Origin 검사만 합니다.
4. 로컬 개발(`npm run dev`)에는 Edge Function이 없으므로 서버 키 모드는 동작하지 않습니다. 설정에서 본인 키를 쓰거나 `npx netlify dev`를 사용하세요.

- Vite + React 18 + TypeScript 5 + Tailwind CSS 4
- 사주 계산은 **코드가 결정론적으로** 수행하고(`src/lib/saju/`), AI는 계산된 결과를 풀이만 합니다.
- Gemini REST API를 브라우저에서 `fetch`로 직접 호출합니다 (SDK 없음).

## 실행

Node.js 18 이상이 필요합니다.

```bash
npm install
npm run dev      # http://localhost:5173
```

## Gemini API 키 발급

1. [Google AI Studio](https://aistudio.google.com/app/apikey)에 접속해 Google 계정으로 로그인합니다.
2. **Create API key**로 키를 만들고 `AIza...`로 시작하는 문자열을 복사합니다.
3. 앱의 첫 화면에 붙여넣고 **키 확인**을 누릅니다. (무료 등급은 분당/일일 요청 한도가 있습니다.)

기본 모델은 `gemini-3-flash-preview`이며 설정(상단 "설정")에서 `gemini-2.5-flash`, `gemini-2.5-pro` 등으로 바꿀 수 있습니다. 모델 목록·타임아웃 등은 [`src/constants.ts`](src/constants.ts)에 모여 있습니다.

## 보안·개인정보

- 키는 **헤더 `x-goog-api-key`** 로만 전송하며 URL 쿼리스트링에 넣지 않습니다.
- 키는 콘솔에 출력하지 않고, 사용자에게 보이는 오류 메시지는 오류 종류별 고정 문구만 사용합니다(서버 응답 원문을 노출하지 않음).
- 저장 방식: 기본은 `sessionStorage`(탭을 닫으면 삭제), "이 기기에 키 저장"을 체크하면 `localStorage`. 공용 PC에서는 체크하지 마세요. 설정 화면에서 저장된 키를 삭제할 수 있습니다.
- 생년월일 등 입력 정보는 사주 풀이를 위해 **Google Gemini API 호출에만** 사용되며 이 앱이 따로 수집하지 않습니다. (Google의 데이터 처리는 Google 약관을 따릅니다. 무료 등급은 입력이 제품 개선에 사용될 수 있으니 유의하세요.)
- 풀이 기록은 이 브라우저의 `localStorage`에만 저장되며(최대 20건) 개별/전체 삭제할 수 있습니다. 기록에는 입력한 이름·생년월일이 포함됩니다.
- 이름·출생지는 정제(제어문자 제거, 길이 제한)한 뒤 JSON 데이터 필드로만 전달하고, 시스템 프롬프트에서 해당 필드의 지시문을 무시하도록 지시합니다(프롬프트 인젝션 방어). 완전한 방어는 보장되지 않습니다.
- 클라이언트 앱 특성상 브라우저 개발자 도구의 네트워크 탭에서는 본인의 키가 보입니다. 키는 본인 브라우저에서만 사용하세요.

```
    storage.ts          키·모델·기록 저장 (모든 접근 try/catch)

```

## 사주 계산 방식과 한계

- 년·월주는 **절기(입춘 등) 시각 기준**으로 판정합니다. 라이브러리의 절기 시각이 UTC+8 기준이므로 입력 시각(KST)에서 1시간을 빼서 판정합니다. (예: 2024 입춘 = KST 2/4 17:27 경계 테스트 포함)
- 시주는 일간 기준 오서둔(五鼠遁)으로 계산합니다. 자시(23:00~)는 입력 화면에서 **정자시(23시부터 다음 날, 기본)** 와 **야자시(당일 유지)** 중 선택합니다. 유파에 따라 다르므로 결과가 다르게 보일 수 있습니다.
- 십성의 지지 기준은 **지장간 본기**, 지장간 표기 순서는 본기 → 중기 → 여기입니다.
- 대운은 성별·년간 음양에 따라 순행/역행하며, 시작 나이는 "3일 = 1년" 환산 + **세는나이** 기준입니다.
- **적용하지 않는 것**: 한국의 역사적 표준시 변경(1908~1911, 1954~1961 UTC+8:30 등), 서머타임(1948~51, 1955~60, 1987~88), 동경 127.5° 지방시(약 -30분) 보정. 해당 시기·절기/자시 경계 부근 출생자는 실제와 다를 수 있습니다.
- 태어난 시간을 모르면 정오로 가정해 년·월·일주만 구하므로 절기 당일 출생은 월주가 부정확할 수 있고, 풀이도 삼주 기준임을 결과에 표시합니다.
- 지원 범위: 1900년 이후 출생 (음력 윤달 포함). 신강/신약·격국·용신은 유파별 차이가 커서 코드로 확정하지 않고 AI의 풀이에 맡깁니다.
- 풀이 요청은 60초 제한(`REQUEST_TIMEOUT_MS`)입니다. `gemini-2.5-pro` 등 느린 모델은 시간이 부족할 수 있어 그럴 땐 상수를 늘리세요.

## 구현 범위

- 필수: API 키 입력/검증 → 정보 입력 → 사주 계산·시각화 → AI 풀이(스켈레톤·취소·재시도) → 결과 탭/게이지/이미지 저장/텍스트 복사, 다크/라이트 모드
- 선택 중 구현: **결과 히스토리(localStorage 저장·삭제)**
- 미구현: 궁합 보기, 스트리밍 응답

> 본 풀이는 재미와 참고용이며 의학·재무·법률적 조언이 아닙니다.
